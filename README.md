## 当前问题定义

### 输入

- `gv.zip` / NCBI RefSeq 来源的天然 GvpA 候选序列；
- recognition JSON 中有 2078 条按完全一致序列合并后的代表序列；
- accession、organism、description、source file 等元数据。

2078 是候选集规模，不等于质量控制后的最终分析规模。`partial`、非标准残基、GvpA/GvpJ 类型冲突和来源缺失均需保留标记并做敏感性分析，不能未经审计直接删掉后仍称为“clean 2078”。

### 标签可行性结论

历史数据库调查未发现可用的天然序列功能差异标签。当前可追溯的 M2 [PF00741 扫描摘要](results/bioinformatics/pf00741_scan_summary.json)记录：2076 条通过序列 QC 的输入全部 accepted（PF00741.24，GA 阈值）。这不是对全部 2078 条候选的功能分类；C 的干净重跑及原始交接已通过助手技术核验，见 [核验报告](reports/M2/a_acceptance_precheck.md)；最终由 A 本人验收。

因此当前数据没有可用于天然序列功能分类的可靠 `y`：

```text
取消主线：sequence -> fabricated function label -> classifier
采用主线：sequence/window -> representation -> candidate region -> independent evidence
```

实验突变记录只用于候选区域冻结后的外部核对，不进入训练、聚类或候选筛选。任何 `Vac+`/`Vac-` 条目必须先完成亲本序列、位点编号、宿主、实验条件和来源表格的逐条映射。

## 研究目标

1. 建立可追溯、带质量标记的天然 GvpA 数据集。
2. 用 ESM-2 残基表示和滑动窗口寻找或复核局部序列模式。
3. 在同源分组的独立验证集上检验候选区域是否稳定。
4. 综合 PF00741 HMM/MSA 保守性、实验突变、已发表结构和残基扰动结果形成证据表。
5. 只报告“潜在功能区域/候选关键位点”，不声称完成湿实验功能证明。

## 研究问题

- **RQ1：区域稳定性。** 蛋白语言模型的局部表示是否能在同源分组的验证集上稳定定位候选区域，而不是只反映序列长度、物种或 C 端延伸？
- **RQ2：多源一致性。** 候选区域是否得到 HMM/MSA 保守性、已审计实验突变和 PDB 结构证据的共同支持？
- **RQ3：关键残基。** 哪些同源位点在残基扰动、保守性、突变和结构证据中持续获得高支持，且显著优于随机区域基线？

### 1. 数据构建

- 上游数据已按完全一致序列合并；CD-HIT/MMseqs2 的主要用途是建立同源簇，不是再次声称得到 2078 条“去重后”数据。
- `partial` 和类型冲突先标记，主分析与敏感性分析分别报告。
- 非标准残基的排除必须保留 `exclusion_reason`。
- 数据划分按同源簇完成。无监督研究也需要 discovery/validation 隔离，避免在同一批样本上发现并验证候选区域。

### 2. 蛋白语言模型表示

当前开发结果采用 `facebook/esm2_t12_35M_UR50D`：每个残基为 **480 维**表示。若更换模型，必须按实际模型记录维度、层、池化方法和版本，不能统一写成 1024 维。

- 全长 mean pooling 用于检查整体异质性和混杂因素；
- 30 aa 窗口、步长 5 用于局部区域分析；
- 聚类在原始表示或 PCA 等保留较多信息的空间中进行；
- UMAP 只用于展示，不把二维图形本身当成功能证据。

### 3. 候选区域与坐标

窗口结果必须映射到同源坐标后比较。当前可用主坐标系是 PF00741 HMM match states；MAFFT 可作为敏感性分析。参考本科论文《基于生物大模型的气囊蛋白元件识别研究》已在同一类2078条GvpA数据上提出 **25–55** 和 **16–46**，因此本项目将二者登记为**预先冻结的假设**并进行独立验证，不能再次描述为本项目原创发现。方法与复用边界见 [论文审计](reports/M1/thesis_method_audit.md)。

### 4. 多源验证

- **保守性：** 在 PF00741 HMM/MSA 列上计算覆盖、熵和保守性，并报告 partial、类型冲突等敏感性。
- **突变：** 只使用能够映射到精确亲本序列和实验表型的记录，且在候选冻结后进行事后核对。
- **结构：** 优先使用已发表的 PDB 7R1C；ESMFold 仅作可选补充。当前开发记录显示 ESMFold API 调用失败，不能写成已完成证据。
- **模型证据：** attention 只称为 sequence-dependency evidence。关键位点至少增加遮挡、掩码或删除扰动，并与随机区域比较。

## 主要风险

1. **循环验证：** 同一批序列或同一Pfam证据不能同时用于发现和独立验证。
2. **坐标错位：** 原始序列位置、窗口位置、HMM列、文献编号和PDB编号必须显式映射。
3. **混杂因素：** 聚类可能主要反映长度、C端延伸、物种或partial状态。
4. **attention误读：** attention不是残基功能的因果归因。
5. **突变证据异质：** 不同宿主、构建体和实验条件不能简单合并为统一标签。
6. **结果先于复现：** 已生成图表仍需绑定提交、输入哈希和独立复跑记录。
