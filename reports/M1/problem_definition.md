# M1 问题定义 v0.2：无监督功能区域识别

状态：**建议路线，待教师确认**。本文件替代“为2078条天然GvpA构造功能类别”的旧设想。

## 1. 研究问题重定义

原目标“根据天然GvpA序列预测功能类别”缺少可区分、可追溯且独立的监督标签。当前目标改为：

> 基于蛋白语言模型和多源证据融合，识别或复核GvpA潜在功能区域，并给出候选关键残基及证据等级。

模型输出不是 `functional/non-functional` 标签，而是候选区域、同源位点分数、证据来源和不确定性。

## 2. 标签可行性结论

| 来源 | 当前调查结果 | 对监督标签的结论 |
| --- | --- | --- |
| NCBI | 开发分支报告2078条均可查到GvpA类注释 | 证明身份，缺少样本间功能差异 |
| UniProt | 开发分支报告447条可映射，功能文本高度同质 | 覆盖不足，不能形成可靠类别 |
| PF00741 | 开发分支报告2078/2078命中 | 全部阳性；不能作为区分性标签 |
| PF01132 | 开发分支报告0/2078命中 | EF-P OB domain，课程材料编号有误 |
| 文献突变 | 存在候选记录，尚需逐条映射亲本、位点和实验条件 | 仅作冻结候选后的外部核对 |

这些全量计数在进入最终报告前必须在统一环境中独立复跑，并记录数据库版本、软件版本、阈值、输入哈希和失败记录。

## 3. 数据对象与质量控制

主候选来自 `gv.zip` recognition JSON，共2078条按完全一致序列合并的代表记录。每条至少保留：

- sequence ID、accession、sequence、sequence hash；
- organism、description、source file；
- length、non-standard residue、partial标记；
- GvpA/GvpJ等类型冲突；
- 纳入队列和排除原因。

2078是候选数，不是最终主分析数。上游已经完成100%一致序列合并；CD-HIT/MMseqs2主要用于同源聚类和数据隔离。`partial`和类型冲突原则上先标记，分别进行主分析与敏感性分析，不把“未检出/未核查”当作负例。

## 4. 发现与验证边界

无监督分析仍可能发生信息泄漏和循环验证。B需按序列相似性建立同源簇，再冻结：

- **discovery set：** 探索窗口表示、确定候选区域和超参数；
- **validation set：** 仅按冻结规则复现候选区域和统计量；
- **sensitivity cohorts：** partial、类型冲突、主要物种组等。

同源簇不能跨discovery和validation。参考本科论文《基于生物大模型的气囊蛋白元件识别研究》已经在2078条GvpA数据上提出25–55和16–46，因此二者直接登记为预先冻结候选，只做验证，不再宣称本项目独立发现。论文方法、结果与项目增量见 [论文审计](thesis_method_audit.md)。

## 5. RQ1—RQ3

- **RQ1：区域稳定性。** 局部ESM-2表示能否在同源分组的验证集上稳定定位候选区域，并排除长度、物种、partial状态和C端延伸等混杂？
- **RQ2：多源一致性。** 候选区域是否同时获得HMM/MSA保守性、已审计实验突变和PDB结构证据支持？
- **RQ3：关键残基。** 哪些同源位点在残基扰动、保守性、突变和结构证据中持续获得高支持，并显著优于随机区域？

## 6. 表示学习与区域分析

当前参考配置：

| 项目 | 规则 |
| --- | --- |
| 模型 | `facebook/esm2_t12_35M_UR50D` |
| 残基维度 | 480 |
| 全长表示 | 去掉特殊token后的残基mean pooling |
| 窗口 | 30 aa |
| 步长 | 5 aa |
| 聚类 | 原始/PCA表示上的HDBSCAN |
| 可视化 | UMAP，仅展示，不作为功能证据 |

如果更换ESM-2模型，必须记录真实维度、层、池化、权重版本和硬件。聚类稳定性至少检查随机种子、PCA维数、HDBSCAN参数、窗口长度和步长。

## 7. 同源坐标与保守性

主坐标系采用PF00741 HMM match states，以处理不同长度和插入缺失。输出必须包含：

- 原始残基位置 ↔ HMM列；
- 窗口 ↔ HMM列覆盖；
- 文献编号 ↔ HMM列；
- PDB 7R1C残基 ↔ HMM列。

保守性报告覆盖率、熵、共识残基和敏感性队列。MAFFT可作为独立敏感性分析；未实际运行前不得写成已完成。

## 8. 残基证据与归因

attention只作为蛋白语言模型的sequence-dependency evidence，不能单独解释为功能重要性。E至少实现一种直接扰动：

- 单残基mask；
- alanine substitution；
- 短窗口遮挡或删除。

扰动分数需绑定明确标量，例如候选簇距离、参考区域表示相似度或预注册的区域稳定性指标。比较扰动、attention、保守性、突变和结构证据，并加入等长度随机区域或随机位点基线。

## 9. 实验突变证据

候选突变表在使用前逐条审计：原论文、亲本序列、位点编号体系、替换残基、Vac表型、宿主/构建体、实验条件及是否可映射。突变记录不参与候选生成和阈值选择，只在区域冻结后验证富集或重合。

不同论文或宿主的 `Vac+`/`Vac-` 不自动视为同一种标签。不能把论文中报告的突变数量直接写成本项目可用样本量。

## 10. 结构证据

优先使用已发表的PDB 7R1C进行二级结构和区域映射。ESMFold只作为无实验结构时的补充；当前开发记录中的ESMFold API请求失败，因此不能列为已完成结果。结构重合支持区域定位，但不等于功能因果证明。

## 11. 证据等级与最终输出

| 等级 | 判定 |
| --- | --- |
| E0 | 仅模型聚类或可视化模式 |
| E1 | 在同源分组验证集上稳定复现，并优于随机基线 |
| E2 | 另有保守性或残基扰动支持 |
| E3 | 同时得到实验突变或已发表结构支持 |

最终交付为：

```text
candidate_region_id
reference_start / reference_end
hmm_start / hmm_end
discovery_rule
validation_effect
perturbation_support
conservation_support
mutation_support
structure_support
evidence_level
limitations
```

未经湿实验只称“候选功能区域/候选关键残基”。
