# C：标签可行性表 v0.1 与来源筛查

核查日期：2026-09-09。对应用户提供的《GvpA功能预测与关键位点归因_小组项目推进方案》§4.1、§9.3：C 负责文献/数据库速查，B/C 共同提出候选标签与来源。本文完成 **C 的来源筛查与可行性意见**，不代替 A 主验或 B/C/D 会签，不宣称已获得可训练的标签表。

## 1. 对当前资料的结论

**C 建议当前 G0 状态为 Rework（需要补齐定义和可追溯标签）。** 仓库尚未定义具体预测属性。B 的审计报告称候选集含 856 条 GvpA、label 全空；Git 中没有该 FASTA、逐样本 metadata、A3M 或教师原始数据包，因而不能独立复算其样本数、物种分布或标签缺失率。856 是 B 报告的数字，不是本次新运行得到的统计。

已检查 main、B、C 分支，以及公开 Releases 和 Issue 正文：没有发现可供 C 分析的真实数据附件。B 的主候选 FASTA 与八种 GVP 识别数据是不同任务，不能自动拿八分类标签替代 GvpA 功能属性。依据：[B 审计报告](https://github.com/Lithium9767/MLP/blob/82ea140d6fc811b5bb37167da927e221d369c609/reports/M1/teacher_data_audit.md)。

## 4. C 提议的证据分级（供 B/C 讨论，未冻结）

| 级别 | 判定 | 用途建议 |
| --- | --- | --- |
| E1：目标属性直接实验 | 精确序列/变体可对应，实验直接测目标属性，来源和条件可追溯 | 作为独立监督标签的优先候选；仍需评估样本量和偏差 |
| E2：数据库人工整理且可追溯实验 | 具体目标字段带实验来源，可回溯到 E1 | 核对后再纳入，不能仅凭 reviewed 状态 |
| E3：相似性/序列模型推断 | 同源转移、规则或 Pfam 命中 | 明确弱监督/辅助证据，不能自动当独立实验事实 |
| EU：未知或冲突 | 缺少目标证据、证据相互矛盾、序列/条件不匹配 | label 保持空或进入人工复核，不当作负例 |

## 5. 标签可以采用前必须满足的事实条件

1. A 组织明确目标、单位/类别、实验条件及未知样本处理；C 核对生物学含义。
2. 每个标签能定位到来源记录或文献图表，并与精确序列/变体对应。
3. B 统计有效标签、缺失、冲突、重复、亲本/物种分布；未知值不自动补零。
4. C 检查标签与 Pfam/MSA 验证是否存在证据循环，尤其不把由相同序列方法推断的标签称为独立实验验证。
5. D/E 结合数据量和同源簇评估任务是否可建模、可划分。文档未规定数值样本量门槛，本报告不擅自设定。
