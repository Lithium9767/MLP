## Corrections needed before relying on significance or merging

1. The reported overlap `p<0.002` uses random windows drawn from all discovery windows with only the cluster's window count preserved. It does not control sequence length, relative/raw position, sequence identity or overlapping-window dependence. Cluster 3 is already strongly length-associated (see [A/D audit](candidate_freeze_decision.md)); these p-values test an unconditional window null and do not establish enrichment beyond those confounds or biological function. Re-run an explicitly matched, sequence-level null and report its coverage and limitations before using an enrichment claim in the PPT.
2. Zero exceedances in 500 permutations are displayed as `p=0.000` in the figure. Report an empirical bound or use a plus-one estimate, and plot the actual simulated null rather than a normal curve reconstructed from mean and 95th percentile. The current figure is only an approximation.
3. `E_coordinate_stats_summary.json` contains literal `NaN` for the unmapped cluster and fails strict JSON parsing. Emit `null` for undefined values. The evidence scaffold fills `hmm_start/end=1/39` from all observed residue states; those are not the candidate majority regions (cluster 1: 16–39; cluster 3: 14–39). Rename these fields or use the predeclared candidate coordinates.
4. Add tests for ID/window/coordinate joins, unmapped cluster 0, split exclusion, matched null construction and strict JSON.
